# 国康直营团队日常管理微信小程序 V1.1

这是可导入微信开发者工具、使用微信云开发部署的原生小程序项目。

## 交付内容

- `miniprogram/`：微信小程序页面
- `cloudfunctions/api/`：唯一云函数入口，包含权限、审批、库存、回款、提成和导入
- `docs/国康直营系统初始数据导入模板.xlsx`：初始数据整理模板
- `docs/微信小程序部署说明_一步一步.md`：从注册到发布的完整操作
- `docs/数据库权限与索引清单.md`：上线必须完成的数据库安全设置
- `docs/初始数据导入操作说明.md`：各类数据导入顺序和规则
- `docs/账号与权限说明.md`：70人账号、角色权限和经理直管规则
- `docs/上线前验收清单.md`：正式给团队使用前逐项打勾

## 部署前必须填写的两项

1. 把 `miniprogram/config.js` 中的云开发环境 ID 替换为实际 EnvId。
2. 把 `cloudfunctions/api/config.js` 中的一次性初始化码替换为自己生成的随机码。

项目里的 `project.config.json` 使用的是体验 AppID。导入微信开发者工具时，必须选择国康自己的小程序 AppID。

## 本地自动检查

在项目文件夹打开命令行，执行：

```powershell
npm.cmd test
```

完整测试范围和最近一次结果见：

- `docs/功能与自动化测试矩阵.md`
- `docs/自动化测试报告_2026-07-24.md`
- `docs/用户使用手册_V1.1.md`

检查通过时会看到：

```text
API路由与12页面契约测试通过
项目结构与安全静态检查通过：12个页面，70个初始账号
全套自动化测试通过：16组测试 + 1组项目静态检查
```

## 重要安全提醒

`国康直营团队_账号清单_可直接导入版.xlsx` 和 `01_人员账号_可直接上传.csv` 含初始明文密码，故意没有放入本项目。只能由老板离线保管、逐人私发，不能上传到云开发、代码仓库或工作群。
