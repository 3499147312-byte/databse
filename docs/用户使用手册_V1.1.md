# 国康直营管理微信小程序 V1.1 用户使用手册

## 一、手册用途

本手册面向老板、总部审核人员、总部财务人员、省区/区域经理、地区主管和业务代表，说明小程序当前已有功能、角色权限及日常操作方法。

系统主要用于：

- 销售日报与零销售日报；
- 销售逐级审核、驳回、退货和作废；
- 仓库库存、批号和有效期管理；
- 客情费用申请、审批、付款和发票闭环；
- 仓库应收、回款登记、财务确认和账期提醒；
- 提成、政策、周任务、风险和审计日志查看；
- 老板查看省区月度业绩、管理人员账号和导入基础数据。

## 二、登录和账号安全

### 1. 首次登录

1. 打开小程序，进入“账号登录”。
2. 输入公司单独发放的登录账号和临时密码。
3. 点击“登录”。
4. 首次登录后，系统会自动进入“首次登录修改密码”。
5. 输入当前临时密码，再输入两次新密码并提交。

新密码至少10位，必须同时包含：

- 大写字母；
- 小写字母；
- 数字；
- 特殊符号；
- 不能包含登录账号或本人姓名。

账号首次登录时会与当前微信绑定。同一个微信不能绑定两个员工账号，一个员工账号也不能同时绑定两个微信。

### 2. 日常登录

账号绑定微信后，仍使用员工账号和密码登录。登录后首页会按本人角色自动显示可使用的功能。

### 3. 密码错误和忘记密码

- 连续输错密码5次，账号会锁定15分钟。
- 忘记密码时联系老板，由老板在“人员与导入 → 人员账号”中点击“重置密码”。
- 老板将新临时密码单独发给员工，员工下次登录必须再次修改密码。

### 4. 更换微信

需要换微信登录时，由老板在人员账号中点击“解绑微信”。解绑后，员工可在新微信上重新登录并绑定。

### 5. 修改密码和退出

进入“我的账号”可以：

- 查看姓名、角色、登录账号和所属区域；
- 点击“修改密码”主动改密；
- 点击“退出登录”清除当前登录状态。

## 四、首页

登录后首先进入首页。不同角色看到的内容不同。

### 1. 经营指标

- 代表、主管、经理和老板：今日销售额、本月销售额。
- 代表、主管和经理：今日提成、本月提成。
- 经理、老板和总部财务：本月应回款、本月已到账。
- 主管、经理和老板：今日未填日报人数。
- 所有角色：本人权限范围内的待处理数量。

只有已经完成最终审核、未退货且未作废的销售才计入销售额和提成。

### 2. 回款提醒

经理、老板和总部财务可以看到：

- 三日内即将到期的应收；
- 已经逾期但未结清的应收；
- 应回、已回、未回金额及到期日期。

点击提醒可直接进入“仓库回款”处理。

### 3. 今日管理提醒

根据角色显示：

- 代表日报提交情况；
- 销售、费用、政策和回款待办；
- 主管和经理的周统计任务；
- 总部审核人员可查看的政策和费用数量；
- 总部财务人员待付款、待收票和待确认回款数量。

页面支持下拉刷新。

## 五、销售日报

### 1. 有销售时填报

操作人：业务代表。

1. 首页点击“销售日报”。
2. 在“客户/门店”中选择实际销售门店。
3. 选择产品规格。
4. 输入销售数量，数量必须是正整数。
5. 输入仓库现有的有效销售批号。
6. 点击“加入销售清单”。
7. 一张销售单有多个产品或批号时，重复第2至6步。
8. 检查“本单产品明细”；错误明细可点击“删除”。
9. 点击“整单提交给主管审核”。

同一产品和同一批号的重复明细会自动合并。系统会校验门店、客户、代表和仓库是否属于同一经理团队，并检查批号是否存在、是否过期。

### 2. 今日没有销售

操作人：业务代表。

1. 进入“销售日报”。
2. 确认“今日日报”显示“尚未提交”。
3. 点击“今日无销量，提交零销售日报”。
4. 确认后，今日日报显示“已经提交/已完成”。

零销售日报不会产生销售额、提成、库存变化或应收，只表示该代表当天已完成日报。

### 3. 销售审核

#### 有主管的代表

1. 代表提交后状态为“待主管审核”。
2. 主管进入“审核中心 → 销售”。
3. 核对日期、代表、客户、产品、数量、批号和金额。
4. 点击“通过”，销售转为“待经理审核”；或点击“驳回”并填写2至200字原因。
5. 经理进入“审核中心 → 销售”进行最终审核。

#### 经理直管代表

代表提交后跳过主管，直接进入“待经理审核”。

#### 经理最终通过

经理点击通过时，系统再次检查实际批号库存：

- 库存充足且批号有效：销售变为“已通过”，扣减库存，销售额、提成、客情额度和仓库应收生效。
- 库存不足或批号过期：系统拒绝通过，不会产生负库存。

驳回的销售不扣库存、不计业绩、不产生提成和应收。

### 4. 退货和作废

操作人：老板，或该团队经理。

1. 进入“销售日报”的销售记录。
2. 找到状态正常的“已通过”销售。
3. 点击“退货”或“作废”。
4. 填写2至200字原因并确认。

完成后系统会：

- 把原销售数量返还到对应批号；
- 标记为“已退货”或“已作废”；
- 重新计算销售业绩、提成和应收；
- 写入纠错记录和审计日志。

## 六、审核中心

### 1. 主管

可以处理本人管理范围内：

- 待主管审核销售；
- 待主管审核费用。

### 2. 经理

可以处理本人团队内：

- 待经理审核销售；
- 待经理审核费用。

### 3. 老板

可以查看并最终处理“待老板审核”的客户政策。

### 4. 总部审核人员

页面名称显示为“政策与费用查看”，可以查看全部政策和费用，但没有“通过”或“驳回”按钮。

### 5. 驳回要求

销售、费用或政策驳回时必须填写2至200字原因。状态变化后，需要相关人员根据原因修正后重新提交或重新导入。

## 七、库存管理

### 1. 查看库存

老板、经理、主管和代表可以进入“库存管理”查看权限范围内：

- 仓库与责任经理；
- 各产品库存余额；
- 具体批号、有效期、数量和入库单价；
- 低库存预警；
- 近效期预警。

主管和代表可以查看所属经理负责的仓库，但不能登记入库。

### 2. 登记商业发货入库

操作人：老板或仓库责任经理。

1. 进入“库存管理”。
2. 选择仓库和产品。
3. 输入入库数量。
4. 输入供货单价。
5. 输入批号。
6. 选择有效期。
7. 点击“确认入库”。

注意：

- 数量必须是正整数；
- 有效期不能早于当前日期；
- 同一仓库、同一产品、同一批号不能使用两个不同有效期；
- 已存在的相同批号会增加库存数量并更新单价；
- 系统同时生成库存流水。

## 八、费用报销

### 1. 代表提交费用

允许的费用类型：

- 奶茶；
- 饮料；
- 小礼品；
- 推广费。

操作步骤：

1. 首页进入“费用报销”。
2. 选择客户。
3. 查看该客户本月当前可用额度。
4. 选择费用类型。
5. 输入报销金额。
6. 填写2至200字用途说明。
7. 点击“提交费用审批”。

客情可用额度来自已经最终通过销售产生的客情空间。待审核和已通过费用都会占用额度，超额度不能提交或不能最终通过。

奶茶、饮料自动标记为“无需发票”；小礼品、推广费进入“待收票”。

### 2. 费用审批

- 有主管：代表提交 → 主管审核 → 经理最终审核。
- 经理直管代表：代表提交 → 经理最终审核。
- 经理最终通过后，费用状态为“已通过”，付款状态进入“待付款”。

### 3. 付款和收票

操作人：老板或总部财务。

1. 进入“费用财务”或“费用报销”。
2. 找到已通过费用。
3. 实际付款完成后点击“确认付款”。
4. 需要发票的费用，实际收到发票后点击“确认收票”。

只有实际完成付款或收票后才能点击确认，避免系统状态与财务实物不一致。

## 九、仓库回款

使用角色：经理、老板、总部财务。

### 1. 应收计划

页面显示：

- 销售月份；
- 仓库；
- 负责人经理；
- 到期日期；
- 应回、已回、未回金额；
- 当前回款状态。

应收金额来自该仓库当月已通过且未退货、未作废的销售。到期日按“销售月月底 + 仓库账期天数”计算。

### 2. 登记回款

1. 进入“仓库回款 → 应收计划”。
2. 找到对应仓库和月份。
3. 点击“登记回款”。
4. 填写实际到账日期。
5. 输入到账金额，最多保留2位小数。
6. 可填写银行流水号。
7. 填写2至200字说明。
8. 点击“确认登记”。

登记金额不能超过当前未回金额，到账日期不能晚于今天。

状态规则：

- 经理登记：进入“待财务确认”；
- 总部财务登记：直接显示“财务已确认”；
- 老板代登记：直接显示“老板已核实”。

### 3. 确认回款

老板或总部财务在“回款明细”找到待确认记录，核对实际银行到账后点击“核实到账”或“财务确认”。

### 4. 撤销回款

- 老板和总部财务可撤销尚未作废的回款；
- 经理只能撤销本人登记、本人团队且尚未确认的回款；
- 撤销必须填写原因；
- 撤销后，该金额会从已回金额中扣除并恢复为未回金额。

### 5. 设置仓库账期

操作人：老板。

1. 进入“仓库回款 → 仓库账期”。
2. 找到仓库，点击“设置账期”。
3. 选择责任经理。
4. 输入0至365天的账期。
5. 点击“保存账期”。

每个启用仓库都必须设置责任经理。责任经理及其下属主管、代表可查看该仓库；其他经理团队不可见。

## 十、经营报表

使用角色：代表、主管、经理和老板。

### 1. 提成

显示本月销售额、销量、提成和客情空间：

- 代表查看本人代表提成；
- 主管查看本人主管提成；
- 经理查看本人经理提成；
- 老板查看各经理汇总。

经理直管代表的销售不产生主管个人提成，原主管提成并入经理提成。

### 2. 政策

查看权限范围内客户政策，包括价格、推广空间、预计月销、有效期和审核状态。只有“老板已通过”且在有效期内的政策才会作为销售和费用规则。

### 3. 周任务

- 主管：按客户形成每周统计任务；
- 经理：按负责区域形成每周统计任务；
- 老板：查看全部经理和主管周任务。

任务完成后点击“提交周统计”。周五及周末仍未提交时，首页提醒会升级。

### 4. 风控

系统自动显示：

- 库存低于100盒；
- 180天内到期的批号；
- 待老板审核政策；
- 逾期未结清应收；
- 待核实回款。

### 5. 财务

老板可在经营报表中查看已通过费用，并确认付款和收票。总部财务主要通过“费用财务”入口处理。

### 6. 日志

- 老板查看全部审计日志；
- 其他经营角色查看本人操作日志。

日志包括操作者、动作、业务对象、说明和时间。

## 十一、省区月度业绩

操作人：老板。

1. 首页点击“省区月度业绩”。
2. 选择“本月”或“上月”。
3. 查看经理排名。
4. 展开查看各经理的产品销量和仓库销售明细。

排名只统计已通过、未退货、未作废的销售。没有业绩的在职经理也会显示为0，便于完整对比。

## 十二、人员与数据管理

仅老板可使用。

### 1. 新增人员

1. 进入“人员与导入 → 人员账号”。
2. 点击“新增人员”。
3. 填写人员编号、姓名、角色、省区/区域、登录账号和临时密码。
4. 根据角色填写上级：
   - 总部审核、总部财务、经理：不填上级；
   - 主管：填写经理人员编号；
   - 代表：填写主管或经理人员编号。
5. 点击“保存人员”。

新增人员首次登录必须修改密码。

### 2. 修改人员

在人员卡片点击“修改”，更改姓名、账号、角色、区域或上级后点击“保存人员”。如果不需要重置密码，临时密码留空。

修改和新增表单位于人员列表下方，需要向下滑动才能看到“保存人员”按钮。

### 3. 停用和启用

- 员工离职或暂时不能使用时点击“停用”；
- 需要恢复时点击“启用”；
- 停用不会删除历史销售、费用、审批和回款记录。

### 4. 重置密码

点击“重置密码”后，系统生成新的临时密码。老板应立即单独复制并发给本人，不要发送到工作群。

### 5. 解绑微信

人员已经绑定微信时显示“解绑微信”按钮。确认解绑后，该账号可绑定新的微信。

### 6. 删除人员

只有完全没有下属、仓库、客户、门店、销售、费用、周报或回款记录的人员才能删除。

有历史业务的离职人员必须使用“停用”，不能删除。

老板账号受保护，不能在此修改、停用、重置、解绑或删除。

## 十三、数据导入

仅老板可使用。当前支持8类数据：

1. 人员；
2. 仓库；
3. 客户；
4. 门店；
5. 产品；
6. 库存入库；
7. 客户政策；
8. 历史销售。

### 通用操作

1. 使用系统提供的Excel模板整理数据。
2. 将对应工作表另存为“CSV UTF-8（逗号分隔）”。
3. 进入“人员与导入 → 数据导入”。
4. 选择数据类型。
5. 点击“选择CSV并预检查”。
6. 查看总行数、新增数、更新数和错误位置。
7. 有错误时修改原文件，重新选择并预检查。
8. 只有错误数为0时，点击“确认正式导入”。

每次最多1000行、文件最大500KB。

### 推荐导入顺序

1. 人员；
2. 仓库；
3. 客户；
4. 门店；
5. 产品；
6. 库存入库；
7. 客户政策；
8. 历史销售。

正式导入前应先备份数据库。不要修改模板中带星号的必填表头，不要保留以 `EXAMPLE-` 开头的示例行。

库存和历史销售导入会预先计算批号余额；导入后会产生负库存时，系统拒绝写入。客户政策导入后状态为“待老板审核”，不会立即生效。

## 十五、推荐日常工作顺序

### 业务代表

1. 每日有销售时提交销售日报；
2. 无销售时提交零销售日报；
3. 查看驳回原因并及时更正；
4. 按真实垫付提交费用；
5. 查看库存、提成和政策。

### 地区主管

1. 检查下属日报完成情况；
2. 审核销售和费用；
3. 查看库存和风险；
4. 完成客户周统计任务。

### 省区/区域经理

1. 检查日报和主管审批；
2. 最终审核销售和费用；
3. 登记本人负责仓库入库；
4. 查看应收提醒并登记回款；
5. 完成区域周统计；
6. 查看团队业绩、提成和风险。

### 总部审核人员

1. 查看全部客户政策；
2. 查看全部费用申请；
3. 发现问题后线下反馈，不能代替老板或经理审批。

### 总部财务人员

1. 处理已通过费用付款；
2. 确认收到发票；
3. 查看应收和回款；
4. 登记或确认实际到账。

### 老板

1. 查看全局指标、日报、审批和回款提醒；
2. 审核客户政策；
3. 查看省区月度业绩；
4. 处理费用付款、收票和回款核实；
5. 设置仓库责任经理和账期；
6. 管理人员账号和基础数据；
7. 定期检查风控和审计日志。

## 十六、常见问题

### 1. 登录提示账号或密码错误

确认账号没有空格、密码大小写正确。连续错误5次需等待15分钟；忘记密码联系老板重置。

### 2. 提示账号已绑定其他微信

联系老板在人员账号中执行“解绑微信”，再用当前微信重新登录。

### 3. 代表找不到门店

检查门店是否启用、是否绑定该代表，以及门店、客户、仓库是否属于同一经理团队。

### 4. 销售批号不可用

检查批号是否存在于对应仓库、库存是否大于0、有效期是否已过。必要时由责任经理先登记入库。

### 5. 经理无法通过销售

常见原因是批号库存不足、批号过期、销售状态已被其他人处理或该销售不属于当前经理。

### 6. 费用提示超过额度

可用额度由本月已通过销售产生，其他待审核或已通过费用也会占用额度。确认客户和金额，必要时等待销售最终通过。

### 7. 回款金额不能登记

金额必须大于0、最多2位小数且不能超过未回金额；到账日期不能晚于今天。

### 8. 人员修改后没有保存

人员编辑表单和保存按钮位于列表下方，请向下滑动到“保存人员”并点击。

### 9. 人员无法删除

只要存在下属、客户、门店、销售、费用、周报或回款等关联数据，就不能删除。离职人员请使用“停用”。

### 10. 数据导入没有“确认正式导入”

预检查仍有错误。根据显示的行号和字段修正CSV，再重新预检查，错误数为0后才会出现正式导入按钮。

## 十七、数据安全要求

- 账号和初始密码必须逐人私发；
- 含密码的Excel或CSV不得上传到代码仓库、公共云盘或工作群；
- 员工离职应立即停用账号；
- 付款、收票、回款只能在实际发生后确认；
- 正式批量导入前必须备份数据库；
- 不要多人共用老板或财务账号；
- 定期查看审计日志和云开发用量告警。
