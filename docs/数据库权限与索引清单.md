# 数据库权限与索引清单

更新日期：2026-07-23

## 一、必须设置为“仅管理端可读写”

本系统的小程序端不直接读数据库，所有操作都经过 `api` 云函数再次检查账号、角色和数据归属。因此下面所有集合都必须设为“仅管理端可读写”，不能选“所有用户可读”或“所有用户可读写”。

1. `users`
2. `warehouses`
3. `customers`
4. `stores`
5. `products`
6. `policies`
7. `inventory_lots`
8. `inventory_moves`
9. `sales`
10. `expenses`
11. `daily_reports`
12. `weekly_reports`
13. `receivables`
14. `warehouse_payments`
15. `corrections`
16. `audit_logs`
17. `idempotency`
18. `settings`

每个集合的操作完全相同：

1. 打开微信开发者工具。
2. 点击顶部“云开发”。
3. 进入“数据库”。
4. 点一个集合。
5. 点“权限设置”或“安全规则”。
6. 选择“仅管理端可读写”。
7. 如果页面要求填写规则，粘贴：

```json
{
  "read": false,
  "write": false
}
```

8. 保存。
9. 对18个集合逐个重复。

设置后，云函数仍能正常读写；小程序页面直接请求数据库会被拒绝。

## 二、建议建立的索引

在“云开发 > 数据库 > 索引管理”中建立。普通字段使用升序，只有 `createdAt`、`registeredAt` 使用降序。

### 第一批：上线前建立

| 集合 | 索引字段，按顺序 |
|---|---|
| `users` | `usernameLower` |
| `users` | `openid` |
| `users` | `personId` |
| `users` | `role`、`disabled` |
| `warehouses` | `managerId`、`status` |
| `customers` | `managerId`、`status` |
| `customers` | `supervisorId`、`status` |
| `stores` | `repId`、`status` |
| `stores` | `supervisorId`、`status` |
| `stores` | `managerId`、`status` |
| `sales` | `repId`、`createdAt`降序 |
| `sales` | `supervisorId`、`status` |
| `sales` | `managerId`、`status` |
| `sales` | `warehouseId`、`settlementMonth`、`status`、`correctionStatus` |
| `expenses` | `repId`、`createdAt`降序 |
| `expenses` | `supervisorId`、`status` |
| `expenses` | `managerId`、`status` |
| `receivables` | `managerId` |
| `warehouse_payments` | `managerId`、`registeredAt`降序 |
| `audit_logs` | `createdAt`降序 |

### 第二批：数据量增大后建立

| 集合 | 索引字段，按顺序 |
|---|---|
| `sales` | `repId`、`status`、`correctionStatus` |
| `sales` | `managerId`、`settlementMonth`、`status`、`correctionStatus` |
| `sales` | `supervisorId`、`settlementMonth`、`status`、`correctionStatus` |
| `sales` | `repId`、`customerId`、`settlementMonth`、`status`、`correctionStatus` |
| `expenses` | `repId`、`customerId`、`expenseMonth`、`status` |
| `policies` | `customerId`、`productId`、`status` |
| `policies` | `managerId`、`status` |
| `policies` | `supervisorId`、`status` |
| `inventory_moves` | `warehouseId`、`productId`、`batchNo`、`status` |
| `daily_reports` | `date`、`repId`、`submitted` |
| `weekly_reports` | `week`、`ownerId`、`status` |
| `warehouse_payments` | `receivableId`、`status` |
| `audit_logs` | `actorId`、`createdAt`降序 |

如果运行时出现“缺少索引”，错误窗口或云函数日志通常会给出需要的字段。按提示新增索引，等待状态变为“可用”，再重试原操作。

## 三、权限验收

1. 用经理甲登录，只能看到经理甲的仓库、客户、销售、费用和回款。
2. 用经理乙登录，不能看到经理甲的数据。
3. 用主管登录，只能审核自己的代表和客户。
4. 用代表登录，只能填写自己覆盖门店。
5. 直接在小程序调试器执行 `wx.cloud.database().collection("users").get()`，应返回权限拒绝。
6. 老板通过正常页面仍可看到全局数据。
