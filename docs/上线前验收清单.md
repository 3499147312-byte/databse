# 上线前验收清单

没有全部打勾前，不要把正式版发给近百人使用。

## 账号与权限

- [ ] 老板能看全局，普通账号不能进入“人员与导入”和“省区月度业绩”
- [ ] 经理甲看不到经理乙的仓库、客户、销售、费用和回款
- [ ] 主管只能审核自己的客户和代表
- [ ] 代表只能看到自己的门店和销售
- [ ] 全部18个数据库集合均为“仅管理端可读写”
- [ ] 首次登录强制修改密码
- [ ] 连续5次密码错误会锁定15分钟
- [ ] 忘记密码可由老板重置，换微信可由老板解绑
- [ ] 离职人员使用“停用”，不直接删除有业务记录的人

## 销售与提成

- [ ] 一张销售单可填写多个产品和批号
- [ ] 代表提交后不立即计业绩，主管和经理通过后才生效
- [ ] 经理直管客户会跳过主管，直接到经理审核
- [ ] 驳回销售不会扣库存、不会计业绩
- [ ] 经理终审库存不足时必须拒绝通过
- [ ] 退货、作废会恢复库存并重算回款
- [ ] 普通240片规则为111.7、3、1.5、0.75、20
- [ ] 120片和40片按规格系数换算
- [ ] 特殊政策只有老板通过后生效
- [ ] 页面金额显示2位，内部计算保留4位
- [ ] 代表、主管、经理首页能看到今日和本月提成

## 日报与周报

- [ ] 有销售的代表提交销售后，今日日报显示已完成
- [ ] 无销售的代表可提交零销售日报
- [ ] 老板能看到今日未填日报人员
- [ ] 主管每个客户有本周统计任务
- [ ] 经理有区域周统计任务
- [ ] 周五未交时首页显示红色提醒

## 库存与批号

- [ ] 入库记录包含仓库、产品、数量、单价、批号和有效期
- [ ] 不同经理不能互看仓库
- [ ] 近效期和低库存有预警
- [ ] 历史销售导入不会造成负库存
- [ ] 同批号不同有效期会被拒绝

## 客情与财务

- [ ] 客情可用额度来自已通过销售的单盒客情空间
- [ ] 主管、经理逐级审核费用
- [ ] 超额度费用不能最终通过
- [ ] 老板能确认付款和收票
- [ ] 不开票返利与需发票费用状态能区分

## 回款

- [ ] 每个仓库已设置负责人经理和账期天数
- [ ] 应回款日期按销售月月底加账期计算
- [ ] 到期前3天在老板和对应经理首页提醒
- [ ] 逾期未结清会持续提醒
- [ ] 经理登记回款后进入老板核实
- [ ] 登记金额不能超过未回金额
- [ ] 撤销回款会同步恢复未回金额并记录原因
- [ ] 老板能看本月应回、本月到账、逾期金额

## 发布与运维

- [ ] 云函数 `api` 上传成功，依赖由云端安装
- [ ] 云函数超时时间设置为60秒，内存至少512MB
- [ ] 已完成数据库索引
- [ ] 已设置云开发用量和费用告警
- [ ] 已用老板、总部审核、总部财务、经理、主管、代表六种角色各测试一次权限和完整流程
- [ ] 初始密码CSV没有上传到代码、云存储或工作群
- [ ] 已导出一次数据库备份并确认能打开
- [ ] 已完成小程序隐私保护指引、服务类目和版本审核
