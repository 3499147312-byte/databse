# 初始数据导入操作说明

## 一、先准备文件

使用同文件夹里的 `国康直营系统初始数据导入模板.xlsx`。

黄色的 `EXAMPLE-` 行只是示范，正式导入前必须删除。编号一旦正式使用，不要随意修改。

小程序直接接收 `CSV UTF-8` 文件。Excel完整模板用于统一整理，每次只把一个工作表另存为CSV：

1. 打开Excel模板。
2. 点要导入的工作表。
3. 删除黄色示例行。
4. 点“文件 > 另存为”。
5. 文件类型选择“CSV UTF-8（逗号分隔）”。
6. Excel提示“只保存当前工作表”时点“确定”。
7. 不要覆盖原始Excel模板。

## 二、必须按这个顺序导入

1. 人员
2. 产品
3. 仓库
4. 客户
5. 门店
6. 库存入库
7. 客户政策
8. 历史销售

后面的数据会引用前面的编号，顺序错了会提示“人员不存在”“仓库不存在”或“批号不存在”。

## 三、在小程序里导入

1. 使用老板账号登录。
2. 首页点“人员与导入”。
3. 点“数据导入”。
4. 选择数据类型。
5. 点“选择CSV并预检查”。
6. 选择刚保存的CSV。
7. 看到红色错误时，按“第几行、哪个字段”回Excel修改，再重新另存CSV。
8. 错误为0时，点“确认正式导入”。
9. 看到“新增多少行、更新多少行”后再进行下一类。

同一个编号再次导入会更新原记录，不会无条件新增一份。库存和历史销售使用来源单号防重；中断后可用同一文件重新预检查。

## 四、人员填写规则

- 总部审核人员：上级人员编号留空，只能查看全部客户政策和费用申请，不能执行审批。
- 总部财务人员：上级人员编号留空，可以处理已审批费用、仓库应收款和回款，不能审批销售和客户政策。
- 经理：上级人员编号留空。
- 主管：上级填写经理人员编号。
- 代表由主管管理：上级填写主管人员编号。
- 代表由经理直接管理：上级直接填写经理人员编号，由经理审核销售。
- 新增人员：必须填临时密码。
- 系统已预置账号：登录账号保持一致，临时密码可留空。
- 临时密码至少10位，包含大写字母、小写字母、数字和特殊符号。

老板账号受系统保护，不放入人员上传CSV；新部署初始化时会自动创建，且只能是吴政锐一人。账号发放、密码和旧账号处理请以离线文件 `国康直营团队_账号清单_可直接导入版.xlsx` 为准。

不要删除已有业务记录的人员。人员离职时应改为“停用”，这样历史业绩、费用、审批和回款仍可追溯。

## 五、客户和门店填写规则

- 普通客户：主管编号和经理编号都填。
- 经理直管客户：主管编号留空，只填经理编号。
- 一个大连锁可以有多个代表覆盖不同门店。
- 连锁总业绩归客户所属主管和经理；代表只计算自己覆盖门店产生的销售。
- 经理直管代表产生销售时，不产生主管个人提成；原主管提成金额并入经理提成。
- 门店、代表、客户和仓库必须属于同一个经理范围。

## 六、价格、提成和客情规则

普通客户未备案特殊政策时，以240片黄芪片为基准：

- 销售价：111.7000元/盒
- 代表提成：3.0000元/盒
- 主管提成：1.5000元/盒
- 经理提成：0.7500元/盒
- 客情额度：20.0000元/盒

120片按0.5倍、40片按1/6倍换算。系统内部保留4位小数，页面和结算显示2位。

98元价格、10元客情额度及其他特殊客户规则，必须在客户政策表按实际产品规格填写。特殊提成只在最后三列填写；普通客户留空。政策导入后状态为“待老板审核”，老板通过后才会用于新销售。

已提交销售保存当时的价格、提成和客情规则快照。以后修改政策不会倒改历史账。

## 七、库存和历史销售

- “商业发货申请”代表库存入库。
- 仓库名称来自“商业公司建档备案”。
- 每个仓库必须填写一名省区/区域经理作为责任人。
- 责任经理及其全部下属主管、业务代表都能查看该仓库；其他经理团队不能查看。
- 只有责任经理和老板可以登记仓库入库，主管和代表只能查看库存。
- 库存必须填写仓库、产品、批号、有效期、数量和供货单价。
- 同仓库、同产品、同批号不能出现不同有效期。
- 历史销售必须在对应批号入库之后导入。
- 历史销售导入后如果造成负库存，系统会拒绝。
- 同一个销售单号可有多行产品，但日期、代表、客户、门店和仓库必须一致。

## 八、导入后必须做的事

1. 老板进入“审核中心”，逐条审核客户政策。
2. 进入“库存管理”，核对各仓库、产品、批号数量。
3. 进入“省区月度业绩”，核对本月和上月经理金额及产品数量。
4. 抽查3个客户的销售价、提成和客情额度。
5. 抽查一个仓库的销售金额、应回款金额和到期日。
6. 在“人员与导入”中停用账号发放清单“旧账号处理”页列出的7个旧账号。
7. 逐人私发账号和临时密码，确认首次登录后已修改密码。
