# 国康直营管理微信小程序 V1.2 权限体系升级与验收

更新日期：2026-07-26

## 1. 升级结果

V1.2保留V1.1的六种组织岗位和审批链，新增权限角色、个人权限、权限管理员、高危申请和审批代理。

最终权限按以下顺序计算：

`权限角色模板 + 个人追加/替换 - 个人禁用 - 已到期授权`

组织岗位仍决定上下级和团队归属；销售、费用审批顺序、负库存、政策状态、提成、应收等业务规则仍由云函数强制执行。

## 2. 新增数据库集合

- `permission_roles`：六个内置模板和老板创建的自定义模板。
- `user_permissions`：人员的继承、追加、替换、禁用及有效期。
- `permission_admins`：权限管理员的人员、团队、区域范围和授权上限。
- `permission_requests`：高危权限申请和老板处理结果。
- `approval_delegations`：销售、费用的团队、阶段、代理人和期限。

这5个集合与原18个集合一样，必须设置为“仅管理端可读写”。

## 3. V1.1升级步骤

1. 导出备份 `users`、`settings`。
2. 新建上述5个空集合并锁紧权限。
3. 上传V1.2云函数。
4. 编译V1.2小程序端。
5. 老板进入“权限中心”，执行幂等迁移。
6. 检查 `permission_roles` 有6条内置模板。
7. 检查70个 `users` 记录均有 `permissionRoleId`、`permissionVersion`、`reauthRequired`。
8. 完成六种岗位真机验收后再上传体验版。

未绑定模板的账号在迁移期间会临时按V1.1岗位模板运行，不会因升级中断登录。

## 4. 回滚

重新部署V1.1云函数和小程序端即可。原 `role` 字段和全部历史业务数据未删除，V1.1会忽略新增权限字段。保留5个权限集合，不要在回滚时清空。

## 5. 验收清单

- [ ] 六个内置模板升级前后权限等效。
- [ ] 老板账号固定使用系统所有者模板，不能编辑、停用或降权。
- [ ] 自定义角色可以创建、修改、停用并绑定人员。
- [ ] 个人“禁用”优先于模板、追加和替换。
- [ ] 团队、区域、客户、仓库范围分别通过正向和越权用例。
- [ ] 权限管理员不能管理自己、老板或其他权限管理员。
- [ ] 权限管理员不能超出授权上限或下发权限管理能力。
- [ ] 高危授权填写原因、二次确认，并由老板通过或驳回。
- [ ] 临时授权到期后返回 `GRANT_EXPIRED`。
- [ ] 普通收回下一次请求生效，高危收回返回 `REAUTH_REQUIRED`。
- [ ] 销售和费用代理不能跳阶段，原审批人与代理先处理者生效。
- [ ] 授权、收回、角色修改和代理均写入审计日志。
- [ ] 人员新增、修改弹窗的保存与取消按钮始终可见。
