# 国康直营团队日常管理微信小程序部署说明

版本：V1.1  
核对日期：2026-07-23

这份说明按第一次接触小程序开发来写。每一步都做完并看到“成功”再继续，不要跳步骤。

## 第一部分：您要提前准备

1. 四川国康药业有限公司营业执照资料。
2. 一个用于注册小程序的邮箱，不能已经绑定其他微信公众平台账号。
3. 法人或管理员微信。
4. 可以接收验证码的手机号。
5. Windows电脑和稳定网络。
6. 本项目文件夹 `guokang-wechat-miniprogram`。
7. 机密文件 `outputs/account-import-20260724/国康直营团队_账号清单_可直接导入版.xlsx`。该文件不要发群、不要上传云端。
8. 人员上传文件 `outputs/account-import-20260724/01_人员账号_可直接上传.csv`。

正式上线还可能涉及微信认证、备案、服务类目和隐私保护指引，具体要求及费用以微信公众平台当时页面为准。

## 第二部分：注册公司小程序并取得AppID

1. 浏览器打开 [微信公众平台](https://mp.weixin.qq.com/)。
2. 点右上角“立即注册”。
3. 选择“小程序”。
4. 按页面填写邮箱、密码和验证码。
5. 主体类型选择“企业”。
6. 填写四川国康药业有限公司主体资料。
7. 按页面要求完成管理员绑定、主体认证和备案。
8. 登录小程序后台。
9. 打开“开发 > 开发管理 > 开发设置”。
10. 找到 `AppID（小程序ID）`，把它记在纸上或密码管理器里。

成功标志：您能看到一个以 `wx` 开头的AppID。

## 第三部分：安装微信开发者工具

1. 打开 [微信开发者工具官方下载页](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 下载Windows稳定版。
3. 双击安装，保持默认选项即可。
4. 打开开发者工具。
5. 用小程序管理员微信扫码登录。

成功标志：开发者工具首页能看到“+ 导入项目”。

## 第四部分：导入本项目

1. 点击“+ 导入项目”。
2. 项目目录选择：

```text
C:\Users\wu\Documents\yewuy\guokang-wechat-miniprogram
```

3. AppID选择第二部分取得的国康小程序AppID。
4. 项目名称填写“国康直营管理”。
5. 后端服务选择“微信云开发”或“使用云开发”。
6. 点“导入”。
7. 如果提示 `project.config.json` 里是体验AppID，选择“使用当前账号AppID”。

成功标志：左边能看到 `miniprogram` 和 `cloudfunctions` 两个文件夹，中间出现国康登录页。

## 第五部分：创建正式云开发环境

1. 在开发者工具顶部点击“云开发”。
2. 第一次使用时，同意服务协议和授权。
3. 点击“创建环境”。
4. 环境名称填写 `guokang-prod`。
5. 选择离团队主要使用地区较近的中国大陆地域。
6. 套餐按页面提示选择。开发测试可先用开发期环境；近百人正式使用前，应查看调用量和正式套餐价格。
7. 点击创建，等待几分钟。
8. 创建完成后进入“设置 > 环境设置”。
9. 找到“环境ID / EnvId”，复制完整内容。

成功标志：环境状态正常，并得到类似 `guokang-prod-xxxxxxxx` 的EnvId。

不要建立多个名字相近的正式环境。数据库、云函数和文件在不同环境中相互隔离，选错环境会表现为“账号和数据全部不见了”。

## 第六部分：填写环境ID

1. 在开发者工具左边展开 `miniprogram`。
2. 点击 `config.js`。
3. 找到：

```javascript
envId: "请替换成云开发环境ID"
```

4. 只把引号里面的中文替换为第五部分复制的EnvId。
5. 保留英文双引号、逗号和其他文字。
6. 按 `Ctrl + S` 保存。

正确示例：

```javascript
envId: "guokang-prod-1a2b3c4d"
```

成功标志：点击顶部“编译”后，登录页不再显示“还差一步配置”。

## 第七部分：设置一次性初始化码

这个码只在第一次创建数据库和70个初始账号时使用。

1. 用密码管理器生成一个至少20位的随机字符串，包含大小写字母、数字和特殊符号，不要有空格。
2. 在左边展开 `cloudfunctions > api`。
3. 打开 `config.js`。
4. 找到：

```javascript
setupCode: "请改成16位以上随机初始化码"
```

5. 只替换引号里的中文。
6. 把这个初始化码临时记在安全位置。
7. 按 `Ctrl + S` 保存。

不要把初始化码写进部署群消息。初始化成功后系统会自动禁止再次初始化。

## 第八部分：上传云函数

1. 查看开发者工具左上或云开发面板，确认当前环境是 `guokang-prod`。
2. 在左边右键点击 `cloudfunctions/api` 文件夹。
3. 选择“上传并部署：云端安装依赖”。
4. 不要选择“忽略依赖”。
5. 等待上传和依赖安装完成。
6. 打开“云开发 > 云函数”，确认出现名为 `api` 的函数。
7. 点击 `api`，进入配置。
8. 把超时时间设置为60秒。
9. 把内存设置为512MB或更高。
10. 保存配置。

成功标志：`api` 云函数状态正常，部署日志没有红色失败信息。

如果提示依赖安装失败，先确认网络正常，再右键选择“上传并部署：云端安装依赖”重试。项目要求安装 `wx-server-sdk`，不能只上传代码不装依赖。

## 第九部分：第一次初始化

1. 点击开发者工具顶部“编译”。
2. 在模拟器登录页向下找到“只在第一次部署时使用”。
3. 点击“初始化数据库和账号”。
4. 输入第七部分设置的一次性初始化码。
5. 点击确定。
6. 等待“初始化完成，已创建70个账号”。

成功标志：

- 云开发数据库出现18个集合。
- `users` 集合有70条账号记录。
- `products` 集合有240片、120片、40片三条初始产品。

如果提示“系统已经初始化”，说明这一步以前成功过，不要重复处理。

如果提示“创建集合失败”，在“云开发 > 数据库”中按《数据库权限与索引清单》列出的18个名称手动新建空集合，然后再次点击初始化。

## 第十部分：立刻锁紧数据库权限

完成初始化后，先不要邀请员工使用。

1. 打开同文件夹里的《数据库权限与索引清单》。
2. 把18个集合逐个设置为“仅管理端可读写”。
3. 按清单建立第一批索引。
4. 等待索引状态全部变为“可用”。

这一步不能省。小程序代码会发到员工手机上，真正的数据隔离必须由云函数和数据库权限共同保证。

## 第十一部分：老板第一次登录

1. 在电脑上打开：

```text
C:\Users\wu\Documents\yewuy\outputs\account-import-20260724\国康直营团队_账号清单_可直接导入版.xlsx
```

2. 打开“账号发放清单”工作表，找到吴政锐的老板账号和初始密码。
3. 回到开发者工具模拟器登录。
4. 系统会要求修改密码。
5. 新密码至少10位，包含大写、小写、数字和特殊符号，不能包含账号或姓名。
6. 修改完成后进入首页。

成功标志：首页显示今日销售、本月销售、回款、未填日报、待审批和工作入口。

账号发放清单只能由老板保管。员工账号和初始密码要一对一私发。

## 第十二部分：整理并导入初始数据

1. 打开 `docs/国康直营系统初始数据导入模板.xlsx`。
2. 按《初始数据导入操作说明》填写。
3. 每个工作表另存为“CSV UTF-8”。
4. 用老板账号进入“人员与导入 > 数据导入”。
5. 严格按以下顺序：

```text
人员 > 产品 > 仓库 > 客户 > 门店 > 库存入库 > 客户政策 > 历史销售
```

6. 每次先“预检查”。
7. 有红色错误时不要强行继续，回Excel修改。
8. 错误为0后再点“确认正式导入”。
9. 客户政策导入后，老板进入“审核中心”逐条通过或驳回。

注意：

- 全新部署V1.1初始化后已经有70名人员，不必重复导入人员账号。
- 已经运行过旧版的系统，先上传 `01_人员账号_可直接上传.csv` 更新69名非老板人员，再按账号清单“旧账号处理”页停用7个旧账号。
- 老板账号不在人员上传CSV中，由系统保护并在初始化时自动创建。
- 经理直管客户的主管编号留空。
- 商业公司建档备案中的商业公司是仓库。
- 每个仓库必须绑定责任经理；该经理的主管和代表自动获得仓库查看权限。
- 商业发货申请是库存入库。
- 库存必须先于历史销售导入。
- 黄色 `EXAMPLE-` 示例行必须删除。

## 第十三部分：六种角色试运行

至少准备老板、总部审核、总部财务、经理、主管、代表六个测试账号。一个微信只能绑定一个员工账号，人员管理中可以解绑后换账号继续测试。

1. 代表登录，修改初始密码。
2. 代表提交一张含两个产品的销售单。
3. 主管登录，在审核中心通过。
4. 经理登录，最终通过。
5. 检查库存是否扣减。
6. 检查代表、主管、经理首页提成是否增加。
7. 代表提交一笔奶茶费用。
8. 主管和经理逐级审核。
9. 总部审核人员确认能查看全部政策和费用，但页面没有通过、驳回按钮。
10. 总部财务人员确认已审批费用的付款和收票。
11. 经理登记一笔仓库回款。
12. 总部财务人员核对并确认回款。
13. 确认总部财务人员不能审批销售和客户政策。
14. 分别测试销售驳回、退货、作废、回款撤销。
15. 用经理甲确认无法看到经理乙的仓库。
16. 用代表确认无法看到无关客户政策。
17. 代表测试“今日无销量，提交零销售日报”。
18. 老板打开“省区月度业绩”，点经理查看仓库明细。
19. 用一名经理直管代表提交销售，确认跳过主管审核，主管提成为0，原主管提成并入经理提成。
20. 用经理、主管和代表分别确认能看到该经理负责的全部仓库；确认无法看到其他经理负责的仓库。

测试用微信需要换账号时，老板在“人员与导入 > 人员账号”中点击“解绑微信”。

每周至少一次：

1. 打开“云开发 > 数据库”。
2. 导出 `sales`、`inventory_moves`、`inventory_lots`、`expenses`、`receivables`、`warehouse_payments`、`policies`、`users`。
3. 文件夹按日期命名，例如 `2026-07-31_国康云数据库备份`。

1. 先完整备份数据库。
2. 保持 `miniprogram/config.js` 的正式EnvId不变。
3. 右键 `cloudfunctions/api`，重新“上传并部署：云端安装依赖”。

## 常见问题

### 1. 登录页显示“还差一步配置”

`miniprogram/config.js` 没有填EnvId，或修改后没有保存、重新编译。

### 2. 提示“云函数不存在”

`api` 没上传到当前EnvId。确认环境后重新上传并部署。

### 3. 提示“系统暂时无法处理”

打开“云开发 > 云函数 > api > 日志”，查看同一时间的错误。常见原因是依赖未安装、缺少索引或超时时间太短。

### 4. 某经理看不到仓库

检查仓库的负责人经理编号是否正确，经理账号是否已经导入正式人员编号。

### 5. 代表看不到门店

检查门店的业务代表编号、客户编号和仓库编号；三者必须处于同一个经理范围。

### 6. 销售终审失败并提示库存不足

批号库存不够、已过期，或入库导错仓库。先核对商业发货申请，不要为了通过而随意增加库存。

### 7. 特殊价格没有生效

检查客户、产品规格、有效期是否正确，并确认政策状态是“老板已通过”。政策只影响审批通过后的新销售，不倒改旧单。

### 8. 员工忘记密码

老板进入“人员与导入 > 人员账号 > 重置密码”，系统只显示一次临时密码。老板私发给员工，员工登录后必须改密。

### 9. 员工换微信

老板先点“解绑微信”。员工再在新微信里用账号密码登录。

### 10. CSV打开后中文乱码

重新从Excel另存为“CSV UTF-8（逗号分隔）”，不要选择普通CSV。
