# 国康直营管理微信小程序 V1.2 用户使用手册

## 1. 基本原则

V1.2把“组织岗位”和“功能权限”分开。岗位决定团队归属和审批顺序；权限角色与个人调整决定能看什么、能做什么。登录、修改本人密码和退出始终可用。

## 2. 老板使用权限中心

首页进入“权限中心”，可切换以下栏目：

- 角色模板：查看六个内置模板，创建或修改自定义模板。系统所有者模板不可修改。
- 人员权限：给一人绑定一个权限角色，并对单项权限设置继承、追加、替换或禁用。
- 权限管理员：指定其可管理人员、经理团队、区域及可授予权限上限。
- 高危申请：通过或驳回权限管理员提交的高危授权。
- 审批代理：设置销售或费用、主管或经理阶段、经理团队、代理人和期限。
- 权限审计：查看角色修改、授权、收回、高危审批和代理记录。

首次升级时，点击“执行/复查V1.2权限迁移”。该操作可重复执行。

## 3. 个人权限调整

1. 选择人员。
2. 老板可更换权限角色。
3. 选择权限动作。
4. 选择模式：
   - 继承：删除该动作的个人调整，恢复模板。
   - 追加：保留模板范围并增加指定对象。
   - 替换：完全使用个人范围。
   - 禁用：该动作不可执行，优先级最高。
5. 选择本人、下属、本团队、指定范围或全公司。
6. 指定范围可填写区域、经理团队、客户或仓库编号。
7. 临时授权填写截止时间。
8. 高危授权填写原因并完成二次确认。

普通权限保存后下一次操作立即生效。高危权限被收回时，用户会返回登录页，必须重新输入账号密码。

## 4. 权限管理员

老板设置权限管理员时必须同时填写管理范围和授权上限。权限管理员进入同一“权限中心”，只能看到被授权管理的人员。

权限管理员不能管理自己、老板或其他权限管理员，不能创建角色模板，不能授予权限管理能力。普通权限可直接生效；高危权限只能提交申请，等待老板处理。

## 5. 高危权限

高危权限包括人员维护和导入、政策通过/驳回、销售退货/作废、付款、收票、回款核实/撤销及仓库账期设置。

授权必须填写原因并二次确认，可长期有效或设置截止日期。老板在“高危申请”中明确通过或驳回。

## 6. 审批代理

老板可为销售或费用指定代理：

1. 选择业务类型 `sales` 或 `expenses`。
2. 选择阶段 `supervisor` 或 `manager`。
3. 填写经理团队编号、代理人员编号、开始和截止日期。
4. 保存后，原审批人与代理人都能处理，先处理者生效。

代理不会跳过审批阶段。政策不使用审批代理。

## 7. 其他业务功能

销售日报、零销售、库存、费用、回款、经营报表、省区业绩、人员与导入的操作步骤保持V1.1一致。页面入口和数据会按当前有效权限自动显示；即使伪造页面请求，云函数也会再次检查权限范围和业务归属。

人员新增和修改使用弹窗，底部“取消”“保存人员”按钮固定显示，无需滑到页面底部。

## 8. 常见提示

- `PERMISSION_DENIED`：没有该动作权限。
- `SCOPE_DENIED`：有功能权限，但目标数据不在授权范围。
- `GRANT_LIMIT_EXCEEDED`：权限管理员超过老板设定的授权上限。
- `GRANT_EXPIRED`：临时授权已到期。
- `REAUTH_REQUIRED`：高危权限已收回，需要重新输入账号密码。
