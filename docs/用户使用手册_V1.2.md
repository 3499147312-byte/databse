# 国康直营管理微信小程序 V1.2 用户使用手册

更新日期：2026-07-26

本手册重点说明V1.2新增的权限中心、动态授权和审批代理。登录、销售、库存、费用、回款、报表、人员管理和数据导入等日常业务操作，继续参照《用户使用手册_V1.1》。

## 1. 基本原则

### 1.1 岗位与权限分开

V1.2保留六种组织岗位：

- 老板；
- 总部审核；
- 总部财务；
- 省区/区域经理；
- 地区主管；
- 业务代表。

组织岗位决定人员属于哪个团队、上下级是谁、销售和费用按什么顺序审批。权限角色和个人权限调整决定该人员能打开哪些功能、能执行哪些动作、能查看哪些数据。

每个人只能绑定一个权限角色。实际生效权限按以下顺序计算：

`权限角色模板 + 个人追加或替换 - 个人禁用 - 已到期授权`

“禁用”的优先级最高。登录、修改本人密码和退出登录始终可用，不受动态权限配置影响。

### 1.2 权限不能改变业务归属

扩大查看范围不等于改变人员所属团队。例如给海南代表追加广东销售查看权限后，该代表可以查看授权范围内的数据，但仍不能冒充广东代表填报销售。

以下业务规则始终由云函数强制执行，不能靠授权绕过：

- 代表只能以本人身份填报销售和费用；
- 客户、门店、代表和仓库必须属于同一经理团队；
- 销售和费用不能跳过主管、经理审批阶段；
- 经理直管代表继续跳过主管阶段；
- 经理终审销售时仍校验批号、有效期和库存；
- 政策状态、客情额度、提成和应收计算规则保持不变；
- 负库存、重复提交和重复审批继续被拦截。

### 1.3 谁能进入权限中心

- 老板：拥有全部权限中心功能。
- 权限管理员：只能管理老板指定的人员、团队或区域，不能修改模板。
- 普通员工：默认看不到权限中心入口。

如果首页没有“权限中心”，表示当前账号没有权限中心查看能力。

## 2. 老板使用权限中心

老板从首页点击“权限中心”。页面包含“角色模板、人员权限、权限管理员、高危申请、审批代理、权限审计”六个栏目。

### 2.1 首次升级执行权限迁移

V1.1升级到V1.2后，老板只需执行一次：

1. 确认V1.2云函数和小程序端已经部署。
2. 进入“权限中心”。
3. 点击“执行/复查V1.2权限迁移”。
4. 等待“迁移完成”提示。
5. 查看提示中的账号检查数和更新数。
6. 进入“角色模板”，确认出现六个内置模板。

迁移可重复执行，不会重复创建账号，也不会覆盖已经绑定的自定义角色。若提示“更新0个”，通常表示迁移已完成。

### 2.2 六个栏目分别做什么

| 栏目 | 用途 | 谁可操作 |
|---|---|---|
| 角色模板 | 查看内置模板；创建、修改或停用自定义模板 | 仅老板 |
| 人员权限 | 绑定权限角色；对单项权限继承、追加、替换或禁用 | 老板、授权范围内的权限管理员 |
| 权限管理员 | 指定管理对象、授权上限和有效期 | 仅老板 |
| 高危申请 | 查看高危授权申请并通过或驳回 | 仅老板处理 |
| 审批代理 | 设置销售或费用的临时代理审批人 | 仅老板 |
| 权限审计 | 查看模板、授权、收回、高危审批和代理记录 | 老板看全部；权限管理员看本人操作 |

下拉刷新页面可以重新读取最新权限配置。

### 2.3 创建自定义角色

适合多人需要长期使用同一套权限时使用。

1. 进入“角色模板”。
2. 点击“新建自定义角色”。
3. 填写角色名称，例如“区域销售观察员”。
4. 勾选需要的权限动作。
5. 为每项权限选择范围：本人、下属、本团队、指定范围或全公司。
6. 如果包含红色标记的高危权限，填写2至200字原因。
7. 点击底部“保存”。
8. 出现高危确认框时，再点击“确认保存”。

角色编辑窗口底部的“取消”和“保存”按钮固定显示，不需要滑到最底部。

### 2.4 修改或停用角色

1. 在角色列表找到目标模板。
2. 点击“修改模板”。
3. 调整权限、范围或“启用模板”开关。
4. 点击“保存”。

注意：

- “系统所有者”模板属于老板账号，不能修改、停用或降权。
- 修改其他内置或自定义模板会影响所有绑定该模板的人员。
- 停用模板后，已绑定人员会临时按其组织岗位的内置模板运行，建议先调整人员绑定再停用。
- 从模板移除高危权限或停用含高危权限的模板，会要求相关人员重新登录。
- 角色模板界面适合设置本人、下属、本团队或全公司等通用范围；具体区域、客户和仓库建议在“人员权限”中设置。

## 3. 个人权限调整

个人权限用于给某一人做例外设置。一个权限动作一次保存一条调整；需要调整多项权限时，逐项保存。

### 3.1 字段说明

| 字段 | 填写说明 |
|---|---|
| 人员 | 选择被授权或被收回权限的员工 |
| 绑定权限角色 | 仅老板可选择；每人只能绑定一个角色 |
| 权限动作 | 选择要调整的具体功能，例如“查看销售” |
| 调整模式 | 继承、追加、替换或禁用 |
| 权限范围 | 本人、下属、本团队、指定范围或全公司 |
| 指定区域 | 填写人员资料中的省区/区域名称，多个用中文或英文逗号分隔 |
| 指定经理团队编号 | 填经理的人员编号，例如`M001` |
| 指定客户编号 | 填客户记录编号，例如`C001` |
| 指定仓库编号 | 填仓库记录编号，例如`W001` |
| 截止时间 | 可空；格式为`2026-12-31`，当天结束后失效 |
| 授权原因 | 高危授权必填；普通授权也建议填写，便于审计 |

人员编号可在“人员与导入 → 人员账号”的人员卡片查看；客户、仓库编号可在对应基础数据或导入模板中查看。编号必须与系统记录完全一致。

### 3.2 四种调整模式

| 模式 | 含义 | 示例 |
|---|---|---|
| 继承 | 删除该动作的个人例外，恢复角色模板 | 撤销临时授权，恢复经理模板 |
| 追加 | 保留模板范围，再增加指定对象 | 经理保留本团队，同时增加指定客户 |
| 替换 | 不再使用模板范围，完全按本次范围 | 只允许查看广东区域 |
| 禁用 | 该动作不可执行，优先级最高 | 暂停某人查看销售 |

选择“继承”或“禁用”时，范围字段不会扩大权限。选择“指定范围”时，至少填写区域、经理团队、客户或仓库中的一种。

### 3.3 给员工追加普通权限

示例：允许经理M001除本团队外，再查看客户C002。

1. 进入“人员权限”。
2. 人员选择目标经理。
3. 权限动作选择“查看销售”。
4. 调整模式选择“追加”。
5. 权限范围选择“指定范围”。
6. 在“指定客户编号”填写`C002`。
7. 填写授权原因。
8. 点击“保存/提交权限调整”。

普通权限保存后，员工下一次打开页面或发起操作时立即生效，不需要重新登录。

### 3.4 用替换限制查看范围

示例：某人员只能查看广东团队数据。

1. 权限动作选择需要限制的“查看”权限。
2. 调整模式选择“替换”。
3. 权限范围选择“指定范围”。
4. 指定区域填写`广东`。
5. 保存。

替换后原模板范围不再保留。设置前应确认指定区域、团队、客户或仓库编号正确，避免员工看不到原有数据。

### 3.5 临时授权

1. 按普通授权步骤填写动作、模式和范围。
2. 在“截止时间”填写日期，例如`2026-12-31`。
3. 填写原因并保存。

截止日期结束后授权自动失效，无需手工收回。员工执行已到期动作时会提示`GRANT_EXPIRED`。

### 3.6 禁用、收回与恢复

临时禁止某项动作：

1. 选择人员和权限动作。
2. 调整模式选择“禁用”。
3. 填写收回原因。
4. 保存。

恢复模板默认权限：

1. 再次选择同一人员和同一权限动作。
2. 调整模式选择“继承”。
3. 保存。

普通权限被禁用后，下一次请求立即失效。高危权限被收回、模板被降权或代理被停用时，系统会设置重新认证标记，员工必须重新输入账号和密码。

### 3.7 更换人员权限角色

只有老板可以更换：

1. 选择人员。
2. 在“绑定权限角色”选择目标模板。
3. 选择本次同时要保存的权限动作及模式；不需要额外调整时可选“继承”。
4. 如果新角色包含高危权限，填写原因并完成二次确认。
5. 保存后刷新页面，确认人员已绑定目标角色。

更换权限角色不会改变该人员的组织岗位、经理、主管或业务历史。

## 4. 权限管理员

权限管理员适合协助老板处理日常普通授权。最高权限控制权仍由老板保留。

### 4.1 新增权限管理员

1. 老板进入“权限管理员”。
2. 在“人员”中选择目标员工。
3. 至少填写一种管理范围：
   - 可管理人员编号；
   - 可管理经理团队编号；
   - 可管理区域。
4. 在“授权上限”填写允许其下发的权限编码，多个用逗号分隔。
5. 决定是否打开“允许提交高危申请”。
6. 如为临时管理员，填写截止时间。
7. 点击“保存权限管理员”。

三种管理范围是“满足任意一种即可管理”。如果全部留空，管理员虽然能进入权限中心，但看不到可管理人员。

### 4.2 授权上限怎么填

授权上限必须填写权限编码而不是中文名称。例如：

```text
sales.view,inventory.view,expenses.view
```

权限管理员只能处理同时满足以下条件的操作：

1. 目标人员在其人员、团队或区域管理范围内；
2. 权限动作在其授权上限内；
3. 不是权限中心最高控制能力；
4. 高危权限只提交申请，不直接生效。

### 4.3 权限管理员不能做什么

权限管理员不能：

- 管理自己；
- 管理老板；
- 管理其他启用中的权限管理员；
- 创建、修改或停用角色模板；
- 给人员更换权限角色；
- 超过老板设定的授权上限；
- 直接下发高危权限；
- 授予角色模板管理、权限管理员管理、高危审批或代理管理能力。

### 4.4 停用权限管理员

老板在管理员列表找到目标人员，点击“停用”。停用后该人员不再拥有权限中心管理能力，并会被要求重新登录。

如仅需缩小范围或上限，可重新选择该人员，填写新的范围和上限后保存。

## 5. 高危权限

### 5.1 哪些属于高危权限

高危业务权限包括：

- 销售退货或作废；
- 确认费用付款、确认费用收票；
- 核实回款、撤销回款、设置仓库账期；
- 通过或驳回客户政策；
- 新增或修改人员、停用人员、重置密码、微信解绑、删除人员；
- 批量导入数据。

角色模板管理、权限管理员管理、高危申请审批和审批代理管理也属于系统最高权限，只能由老板使用，不能下放。

### 5.2 老板直接下发高危权限

1. 进入“人员权限”。
2. 选择人员和高危权限动作。
3. 选择追加或替换，并设置范围。
4. 填写2至200字授权原因。
5. 点击保存。
6. 在二次确认框点击“确认授权”。

老板确认后立即写入授权。建议高危权限尽量设置截止日期。

### 5.3 权限管理员提交高危申请

权限管理员满足管理范围、授权上限且允许提交高危申请时：

1. 按个人权限调整步骤选择高危动作。
2. 填写原因、范围和截止时间。
3. 完成二次确认并提交。
4. 页面提示“权限已提交”只表示申请已提交，此时权限尚未生效。
5. 等待老板在“高危申请”中处理。

### 5.4 老板通过或驳回申请

1. 老板进入“高危申请”。
2. 检查目标人员、权限编码、申请人和申请原因。
3. 确认合理时点击“通过”，授权才会写入。
4. 不同意时点击“驳回”，系统记录驳回结果且不写入授权。

同一申请只能处理一次。已通过或已驳回的申请不能重复处理。

### 5.5 收回高危权限

如果高危权限来自个人追加或替换，选择“继承”可删除该个人例外；如果高危权限来自角色模板，应选择“禁用”、更换人员角色，或谨慎修改模板。高危权限被移除后，员工下一次请求会提示重新登录，避免旧登录状态继续使用敏感能力。

## 6. 审批代理

审批代理只适用于销售和费用，可代理主管阶段或经理阶段。政策审批不使用代理。

### 6.1 字段填写规则

| 字段 | 可填值或说明 |
|---|---|
| 业务类型 | `sales`表示销售；`expenses`表示费用 |
| 审批阶段 | `supervisor`表示主管初审；`manager`表示经理终审 |
| 经理团队编号 | 被代理业务所属经理编号，例如`M001` |
| 代理人员编号 | 实际代审人员的人员编号，例如`S002` |
| 开始日期 | 格式`2026-07-26`；留空时从当天开始 |
| 截止日期 | 必填，不能早于开始日期 |
| 代理原因 | 建议说明休假、出差等实际原因 |

### 6.2 设置代理

示例：M001团队主管休假，由S002临时代审费用。

1. 老板进入“审批代理”。
2. 业务类型填写`expenses`。
3. 审批阶段填写`supervisor`。
4. 经理团队编号填写`M001`。
5. 代理人员编号填写`S002`。
6. 填写开始日期、截止日期和原因。
7. 点击“保存审批代理”。
8. 在列表确认状态为“启用”。

### 6.3 代理生效规则

- 代理只对指定团队、指定业务、指定阶段和有效期生效。
- 原审批人与代理人都可以处理，先处理者生效。
- 第二人再操作同一记录时，系统会提示状态已经变化或审批层级不正确。
- 代理主管通过后仍需经理终审；代理不能跳过任何阶段。
- 经理阶段不能把代理设置给原经理本人。
- 同一团队、业务和审批阶段在重叠日期内只能有一条启用代理。
- 审批轨迹会记录实际处理人、代理岗位、团队和授权编号。

### 6.4 停用代理

在代理列表找到启用记录，点击“停用”。停用立即生效，代理人会被要求重新登录。历史审批轨迹和审计日志不会删除。

## 7. 其他业务功能

销售日报、零销售、库存、费用、回款、经营报表、省区业绩、人员与导入的操作步骤保持V1.1一致。

V1.2的变化是：

- 首页只显示当前有效权限允许的菜单；
- 页面只返回当前权限范围内的数据；
- 操作按钮按有效权限和记录状态显示；
- 云函数再次校验动作权限、数据范围和业务归属；
- 权限发生变化后，重新进入页面或下拉刷新即可取得最新配置；
- 高危权限收回时必须重新输入账号密码。

人员新增和修改已改为弹窗，底部“取消”和“保存人员”按钮固定显示，无需滑到页面底部。

### 7.1 三个典型结果

1. 有“查看销售”但没有“填报销售”：能打开销售页和查看授权数据，但看不到或不能使用提交能力。
2. 有“查看库存”但没有“登记入库”：能查看仓库库存，但不能登记商业发货入库。
3. 有某区域查看权但不是该团队成员：能查看授权数据，但不能冒充该团队员工提交业务。

## 8. 常见提示

| 提示或错误码 | 含义 | 处理方法 |
|---|---|---|
| `PERMISSION_DENIED` | 没有该动作权限，或该动作已被禁用 | 由老板核对角色模板和个人调整 |
| `SCOPE_DENIED` | 有功能权限，但目标记录不在授权范围 | 核对区域、团队、客户、仓库编号 |
| `GRANT_LIMIT_EXCEEDED` | 权限管理员超出老板设置的授权上限 | 由老板调整上限或亲自处理 |
| `GRANT_EXPIRED` | 临时授权已到期 | 由老板重新授权并设置新截止日期 |
| `REAUTH_REQUIRED` | 高危权限、管理员身份或代理已被收回 | 退出后重新输入账号密码 |
| `CONFIRM_REQUIRED` | 高危授权尚未完成二次确认 | 填写原因并在确认框确认 |
| `INVALID_REASON` | 高危原因或驳回原因过短、过长 | 填写2至200字说明 |
| `REQUEST_NOT_PENDING` | 高危申请已被处理 | 刷新“高危申请”列表，不要重复处理 |
| `DELEGATION_CONFLICT` | 同一团队和阶段存在日期重叠的代理 | 停用旧代理或调整新代理日期 |
| `WRONG_APPROVAL_LEVEL` | 当前记录不在该人员可处理阶段 | 刷新审核列表并确认代理阶段 |

如果权限刚保存但页面没有变化：

1. 下拉刷新当前页面；
2. 返回首页后重新进入；
3. 检查截止日期是否已经过去；
4. 检查填写的是人员、经理团队、客户或仓库的系统编号，而不是姓名；
5. 如提示`REAUTH_REQUIRED`，退出并重新输入账号密码；
6. 仍有问题时由老板查看“权限审计”。

## 10. 老板日常检查建议

每周或权限调整后检查：

1. “高危申请”是否存在长期未处理申请；
2. 临时管理员和临时授权是否设置合理截止时间；
3. 已结束休假或出差的审批代理是否停用；
4. 权限审计中的人员、动作、范围、原因和实际操作人是否合理；
5. 停用员工是否还绑定自定义高权限角色；
6. 随机使用经理、主管和代表体验账号确认菜单和数据隔离正常。
